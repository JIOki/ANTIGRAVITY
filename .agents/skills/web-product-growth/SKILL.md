# Experiencia web y crecimiento

Diseña para que se entiendan rápidamente evento, mercado, operador, selección, cuota, hora de actualización y resultado del cálculo. Diferencia datos incompletos, vencidos y confirmados; muestra vacíos, errores y filtros de forma clara. Considera teclado, contraste, pantallas pequeñas y tablas comparables.

Antes de proponer código, inspecciona el stack y patrones del proyecto. Para recomendaciones de gestión, marketing o ventas, conecta público objetivo, propuesta de valor, canal, costo operativo y métricas observables. Describe cálculos como análisis de cuotas, no como ganancias garantizadas. Mantén cada recomendación dentro del alcance solicitado.
